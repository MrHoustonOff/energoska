# STATE: где мы и что дальше

_Обновляется в конце каждой сессии. Последнее обновление: 02.10.2026._

## Что готово и проверено на iPhone
- Запуск с иконки без чёрных полос; экранная клавиатура для всех видов полей; push-уведомление при закрытом приложении (тест).
- Каркас: оболочка `src/shell.js`, экраны `src/screens/*`, панель вкладок (Главная, Банки, Запись, Цифры, Ещё), Лаборатория (`Ещё → Лаборатория`: поля, push, отладка).
- Документация по каркасу: `docs-src/docs/07-app-shell.md`, `08-push.md`, `09-dev-workflow.md`.

## Что НЕ готово
- Все продуктовые экраны (на панели заглушки с указанием эталона).
- Стек фронтенда (решено Svelte 5 + TypeScript, ещё не внедрён).
- Контракт API и слой данных (`api/`), мок-адаптер.
- Бэкенд (Go + PostgreSQL), хостинг. Подробно: `docs-src/docs/10-architecture.md`.
