## 3. Какой CSS взять (копируй значения дословно)
Только правила, которые реально используются перечисленными в п.1 элементами: `.ib`, `.chip`, `.chip.on`, `.can`, `.stk`, `.num`, `.me`, `.pa`, а также зерно на `.chip` и `.ib` (правило `::after` из блока «фактура»; зерно в приложении уже есть, переиспользуй его, а не добавляй второй раз). Inline-стили плиток (`style="..."`) перенеси в классы `.ct-*` в `src/catalog/catalog.css` с теми же значениями. Меняющееся (цвет банки, поворот) передавай переменными `--c`, `--rot`. Класс `.k-burn{background-image:url(...)}`: в приложении картинка берётся из `Drink.photo.urls.h192`/`h256` (в проходе A пока подставь любую из `public/demo/cans/*-256.webp`).

## 4. Переиспользование, а не копии (проверь ДО написания, `grep` по `src/`)
- Кнопка-иконка 44×44 (`.ib`): в приложении есть `.hm-ib` (`src/home/home.css`, 40px) и стили в `src/auth/auth.css`. Если значения совпадают с эталоном, используй существующее. Если отличаются на пиксели, НЕ правь чужой класс: заведи общий класс в `src/ui/` и сообщи в отчёте, что именно отличается.
- Чип (`.chip`): проверь `src/auth/auth.css`. Если там такой же, вынеси в общий `src/ui/Chip.svelte`, а не дублируй. Если разный, сделай один общий компонент `Chip` с эталонными значениями.
- Стикер-банка (`.can.stk`): это общий компонент `src/ui/StickerCan.svelte` (эталон `docs-src/components/StickerCan/`), потому что банка встретится на карточке, в оценке и на главной. Сделай его сразу общим: пропы `src`, `height`, `rot`.

Если размер/вес шрифта шапки Shell (26px/800) не совпадает с эталоном, не правь Shell: остановись и спроси.

## 6. Качество и оптимизация (обязательно)
- Анимации и переходы только `transform` и `opacity`. Эталонные плитки статичны: ничего не анимируй «для красоты».
- Список длинный: у ПЛИТКИ (не глобально) `content-visibility:auto; contain-intrinsic-size:auto <высота плитки>px` (требование README эталона). Картинки `<img loading="lazy" decoding="async">` или `background-image` с размерами, чтобы не прыгала вёрстка; берётся наименьший подходящий размер (`h192` для плитки, не `h384`).
- Никаких `filter`/`box-shadow` на каждом кадре; `.stk` с `drop-shadow` оставь как в эталоне, на скролле его не пересчитывай (не менять во время прокрутки).
- Цвета только `var(--…)` из токенов. Допустимые литералы только те, что есть в эталоне (`#fff`, `#000` внутри плитки бренда); перечисли их в отчёте.
- Никакого `any`, никаких `!important`, никаких глобальных селекторов (`div`, `span`) в `catalog.css`; все классы с префиксом `ct-`.
- Никаких своих текстов: все надписи только из эталона.
