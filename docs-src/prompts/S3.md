# ЭТАП 3: подключение к API (контракт, мок, правила)

Только после того, как владелец принял этапы 1 и 2. Фронтенд уже нарисован и оживлён на фикстурах (`src/demo-ui/*`, `src/<блок>/source.ts`). Задача: заменить фикстуры настоящим слоем данных, ничего не меняя во внешнем виде. Прочитай `CLAUDE.md`, `docs-src/docs/10-architecture.md`, `11-api-contract.md`, `12-demo-data.md`.

## Порядок (по блокам: Банки → Пара → Справочники → Банка дня → Цифры → Настройки/уведомления; коммит и push после каждого блока)
1. **Контракт.** По фикстурам блока составь список нужных данных и действий. Добавь в `api/openapi.yaml` (OpenAPI 3.0.3) недостающие сущности и эндпоинты, `npm run api:types`, `src/api/types.ts`. Вопросы продукта, где нет решения (цены, магазины, справочник брендов, уведомления, разрыв пары, настоящие фото): выбери простейший разумный вариант, запиши в `docs-src/docs/11-api-contract.md` раздел «Допущения этапа 3» и вынеси в отчёт список вопросов владельцу. Для каталога: в элементы `GET /drinks` добавь `my_score`, `partner_score` (0..100, nullable).
2. **Правила** в `src/domain` (чистые функции + таблица сценариев в тестах): лимит 2 банки в день, граница суток 04:00, итог оценки, выбор «Банки дня», фильтры каталога, статистика и т.д. Всё, что в эталоне считается, считается здесь.
3. **Мок** `src/api/mock`: реализация по контракту на правилах из п.2, контрактные тесты `src/api/contract` проходят и на моке, и (позже) на HTTP.
4. **Демо-генератор** `src/api/mock/demo`: перенеси содержимое фикстур `src/demo-ui` в профили демо (те же банки, имена, оценки, ленты, фото), чтобы экраны на демо-профиле выглядели как эталон. Профили из этапов 1–2 остаются доступны в Лаборатории.
5. **Экраны.** Содержимое `source.ts` блока замени на вызовы `api`. Разметку и CSS не трогай (если пришлось, назови в отчёте). Состояния «пусто/загрузка/ошибка/нет сети» теперь настоящие (из ответов `api`), реестр «Состояний экранов» оставь как переключатель принудительных состояний.
6. Удали `src/demo-ui/*` блока, когда его экраны перестали на него ссылаться.

## Критерий приёмки
`check/test/build` зелёные; `grep -rn "demo-ui" src` пусто; скриншоты профилей демо совпадают со скриншотами этапов 1–2; в отчёте: добавленный контракт (эндпоинты и схемы), правила и тесты, допущения и вопросы владельцу, что не проверено на iPhone.
