# Энергоська: вкус

Полный пакет лежит рядом (AGENTS.md, docs/, components/, tokens/, reference/). Если пакета нет под рукой, действуй по этому краткому своду и скажи пользователю, что подробности не видел.

## Нерушимое
1. Максимум 2 энергетика в день. Лесенка кнопки «Энергоснулся»: 0 живая, 1 затухает («вторая будет последней»), 2 лимит (замёрзла, предлагаем воду). Сверх лимита только удержание 3 с и пометка «сверх лимита». Рекомендации: при 1 банке только лёгкие типы, при 2 всё заблокировано.
2. Считаются только напитки с галочкой «Энергетик»; вода, чай, кола не в счёте.
3. Тёмная тема основная, светлая вторая; один набор токенов. Фирменного цвета нет: цвет только у банок (`can-*`) и игроков (`me`, `partner`, берутся из данных).
4. Unbounded для текста, Oswald для чисел; поля ввода ≥ 16px системным шрифтом. Радиус 12 (круги — полный). Нет размытых теней, нет геометрии на фоне кроме кругов. Фон «Глубина» + слабый PNG-шум.
5. Банка — вырезанный стикер с белой обводкой 2.5px и наклоном ±5° на диске цвета банки. «Фото скоро» — отдельное состояние той же высоты.
6. Оценка `8.6` (точка, шаг 0.1), 4 параметра; фейдеры, не нативный range.
7. Анимации только `transform` и `opacity` (исключение: кольцо удержания). Паузы при скрытой вкладке, шторке, клавиатуре; уровни `data-perf=low|min`.
8. Тексты по-русски, коротко, на «ты», без эмодзи; кнопки глаголом.
9. Каждый ввод имеет состояние «с клавиатурой»; все экраны проверяются в обеих темах и во всех состояниях (пусто, загрузка, ошибка, нет сети, лимит).
10. Меняй только то, что просят; замороженные решения (шторка цены, выбор магазина, бутылка «Водичка», слово «Энергоснулся», стиль) трогай только по прямой просьбе.

## Банка дня
Вкладки «Рандом» (параметры: магазины, бюджет, сахар, объём, новизна, давность, оценки, вкус, ядрёность, исключения; барабан; воронка при пустом результате) и «Рекомендация» (одна на день на пару, детерминированно по `hash(couple+date)`, 24 типа с уникальным оформлением).

## Картинки
Четыре размера банки: XS 96, S 192 (карусель), M 256 (плитка), L 384 (результат, карточка). Список «Банки»: страницы по 24, окно 4 страницы, скелетон того же размера.

## Как работать
Найди ближайшие компоненты в `components/INDEX.md`, повтори их решения, не вводи новых цветов и шрифтов, сообщи, что не удалось проверить (скорость на iPhone), и задай вопрос, если правило не нашлось.
