# Энергоська: пакет «вкус» (taste)

Всё, что нужно ИИ-агенту, чтобы проектировать и разрабатывать Энергоську в одном стиле, ничего не ломая: правила, токены, референс-вёрстка, 44 компонента и экрана со скриншотами в тёмной и светлой темах, логика бэка, правила оптимизации.

## Что внутри
| Путь | Что это |
|---|---|
| `AGENTS.md` | главный файл для агента: нерушимые правила и порядок работы (читать первым) |
| `SKILL.md` | тот же «вкус» в формате навыка (Claude Skills): краткая версия правил + ссылки на пакет |
| `taste.json` | машинный манифест: версия, инварианты, токены, каталог компонентов |
| `docs/` | продукт, визуальный язык, UX-паттерны, бэкенд, производительность, решения |
| `tokens/` | `tokens.json` (источник) и `tokens.css` (готовые переменные и текстовые стили) |
| `reference/` | `energoska.css`: классы эталонной вёрстки; `README.md` о том, что из этого продуктовое, а что леса для макета |
| `components/` | 44 компонента и экрана: `README.md`, `preview.html`, `dark.webp`, `light.webp`; `INDEX.md` — каталог |
| `assets/` | вырезанные банки (WebP), шум фона `grain.png` |
| `tools/` | линтер анимаций, аудит, проверка наложений, нарезка картинок, трассировка |

## Как открывать превью
Каждый `components/<имя>/preview.html` открывается двойным щелчком (токены вшиты, нужен интернет только для шрифтов Unbounded и Oswald). Тема берётся из настроек системы; принудительно: `preview.html?theme=dark` или `?theme=light`. Превью — эталон внешнего вида и вёрстки, а не готовый код приложения: интерактива нет, телефон нарисован «лесами» (`.scr`, `.sb`).

## Как подключить к агенту
**Claude Code / Claude Agent SDK.** Положи папку в корень репозитория как `design/energoska-taste/` и добавь в `CLAUDE.md` строку: «Перед любой UI-задачей прочитай design/energoska-taste/AGENTS.md». Либо положи `SKILL.md` в `.claude/skills/energoska-taste/` вместе с папкой.
**Cursor, Windsurf и др.** Скопируй `AGENTS.md` в `.cursor/rules/energoska.mdc` (или `AGENTS.md` в корне) и оставь пакет в репозитории: агент откроет `components/` по ссылкам.
**Claude Projects / ChatGPT Projects.** Загрузи в знания проекта `AGENTS.md`, `docs/`, `components/INDEX.md`, `tokens/tokens.css`, `reference/energoska.css` и нужные компоненты (скриншоты `.webp` агент видит как картинки).
**Любой агент без файлов.** Вставь `AGENTS.md` в системную инструкцию, а остальное давай по запросу.

## Как просить агента
Хорошо: «Сделай экран X. Ближайшие аналоги: ScreenCatalog и ScreenFilters. Проверь тёмную и светлую темы, состояния пусто/загрузка/нет сети/лимит, прогони tools/lint-anim.py». Агент обязан сказать, на какие компоненты опирался и что не смог проверить (например, скорость на iPhone).

## Как обновлять
Любое изменение дизайн-системы идёт так: правка в проекте → обновление README компонента → пересборка `preview.html` и скриншотов → запись в `docs/06-decisions.md` (принято, заморожено, отклонено, открыто) → увеличение версии в `taste.json`. Пакет собирается из артефакта дизайн-системы «Энергоська» в Claude; чтобы получить свежую версию, попроси Claude пересобрать экспорт.

## Что в пакет не входит
Исходный код приложения (его ещё нет), генераторы превью (Python), реальные фото банок, серверная часть, ключи и данные пользователей. Системная клавиатура iOS на макетах не рисуется.

## Ограничения, о которых стоит помнить
- Скорость и память проверены только в Chromium без экрана и расчётом по размерам файлов, не на iPhone.
- Шрифты Unbounded и Oswald в превью подключаются с Google Fonts; для приложения их нужно положить локально с подмножеством кириллицы.
- Фото банок в пакете — тестовые вырезки четырёх брендов.
