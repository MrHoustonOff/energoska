# ScreenNotificationSetup — включение уведомлений

1. **Не на экране «Домой».** В обычной вкладке Safari iOS не даёт подписаться. Экран в три шага: «Поделиться», «На экран „Домой“», открой Энергоську с экрана. Это требование Apple.
2. **Запрос.** Показываем после установки и по тапу «Разрешить уведомления» (iOS не принимает запрос без жеста). Если пользователь говорит «Не сейчас», напоминаем один раз через несколько дней в «Настройках».
3. **Настройки уведомлений.** Статус, переключатели по типам (Даша пьёт энергетик, пьёт воду, закрыла норму, добавила новое, фото обработано) и тихие часы (по умолчанию 23:00–08:00: пуши не идут, события ждут в «Что нового»). «Пьёт воду» по умолчанию выключен, чтобы не спамить.
4. **Выключено в iOS.** Если пользователь отказал в системном окне, возвращаем его в настройки телефона: Настройки, Энергоська, Уведомления. Переключатели при этом неактивны.
