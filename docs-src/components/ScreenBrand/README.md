# Бренд

Страница бренда: плоская плитка цвета бренда с крупным названием (правило длинных названий работает как везде), чипы «число энергосов» и «выпито», три плитки: моя оценка, оценка партнёра, средняя цена. Переключатель средней цены Все / РБ / РФ. Ниже фильтры и сетка всех энергосов бренда в две колонки: со стикером или плиткой «Фото скоро». Для длинных названий плитка героя выше.


## Оптимизация: как сохранять
Длинный список: content-visibility:auto и contain-intrinsic-size у строки (не глобально), миниатюры WebP с lazy-loading. Анимации строк только transform/opacity. Проверка: lint-anim.py, perf-audit.js.
