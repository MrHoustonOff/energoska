# ScreenLogin — вход

Четыре состояния: ввод с подсказкой iOS «Пароли», неверные данные, блокировка после попыток, отправка.

## Поля (важно для iOS)
- Форма настоящая: `<form>` с кнопкой `type=submit`, чтобы Safari понял, что это вход, и предложил связку ключей.
- Логин: `autocomplete="username"`, `autocapitalize="none"`, `autocorrect="off"`, `spellcheck="false"`, `enterkeyhint="next"`.
- Пароль: `type="password"`, `autocomplete="current-password"`, `enterkeyhint="go"`. Глаз переключает показ.
- Поле логина — первое, пароль — второе, без лишних полей между ними.

## Ошибки
- Неверный логин ИЛИ пароль — одно и то же сообщение: «Вы ввели что-то неверно. Проверьте логин и пароль.» Какое именно поле неверно — не говорим (защита от подбора). Оба поля подсвечены красным.
- Показываем «Осталось N попытки» — предупреждение перед блокировкой.
- После 5 неудачных попыток — блокировка с таймером (0:42): поля и кнопка неактивны, кнопка «Повторить через 0:42». Лимит и таймер считает сервер, а не приложение.
- Любое изменение поля убирает красную подсветку.
- Нет сети: красная строка под кнопкой «Нет соединения. Попробуйте ещё раз», введённое сохраняется.

## Загрузка
Кнопка остаётся белой, внутри спиннер и «Входим…», повторное нажатие отключено.

## Не решено
Восстановление пароля: без почты его нет, поэтому ссылки «Забыли пароль» на экране нет. Нужно решение: оставить так или добавить способ.


## Стартовая инфографика
Вместо банок на входе: сетка цветных блоков (синий с лаймовым кольцом, лаймовый с розовым кругом, розовый с чёрным кругом, красный с чёрным кольцом и точкой). Кольца и круги слегка «дышат» (масштаб 1 → 1,07, 5–7 секунд); при `prefers-reduced-motion` не двигаются.


## Оптимизация: как сохранять
Инфографика без бесконечных анимаций тяжелее transform/opacity; фон-пятна по правилам Performance. Проверка: lint-anim.py.
