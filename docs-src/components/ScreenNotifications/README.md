# ScreenNotifications — как уведомления выглядят и копятся

1. **Экран блокировки.** Системное уведомление: иконка приложения, «ЭНЕРГОСЬКА», время, заголовок и текст. Рисует iOS, мы задаём только заголовок, текст, адрес для тапа и число на иконке. Несколько уведомлений складываются стопкой.
2. **Внутри приложения.** Тост над главной (см. NotificationToasts). На колокольчике в шапке главной красный счётчик непрочитанных.
3. **Возвращение после отсутствия.** Тосты не проигрываются заново. Вместо них на главной карточка «Пока тебя не было» с 3 последними событиями, «и ещё N» и «Открыть всё»; закрывается крестиком. Если накопилось 3 и больше за короткое время, телефон получает один сводный пуш («Даша: 3 события»), а не россыпь.
4. **«Что нового».** Список событий за 30 дней: непрочитанные сверху (жирные, с точкой), потом по дням. Смахивание влево удаляет, «Прочитать все» сбрасывает счётчик и значок на иконке.

## Тексты (до 40 символов в заголовке)
- Даша выпила Lit Strawberry / Её 2-й за сегодня. Ты пока на 1.
- Даша выпила воду / +250 мл, всего 1,5 из 2,25 л. Догоняй.
- Даша закрыла воду / 2250 мл за день. У тебя 1,2 л: ещё стакан-два.
- Даша добавила Burn Apple / Оценка 8.0. Твоей ещё нет, оцени.
- Даша добавила магазин / Евроторг, РБ. Первая цена 3,95.
- Даша добавила бренд / Flash Up. Банок пока нет.
- Фото готово / Burn Яблоко-киви: фон убран, банка в каталоге.
- Фото не вышло / Не нашли банку на снимке. Сфоткай ближе.

## Что можно и нельзя на iOS (проверено по документации WebKit и обзорам)
- Web Push работает только в приложении, добавленном на экран «Домой», на iOS и iPadOS 16.4 и новее. В обычной вкладке Safari уведомлений нет.
- Разрешение запрашивается только по тапу пользователя (отсюда экран «Разрешить уведомления»), системное окно iOS показывает сам.
- Значок-счётчик на иконке (Badge API) поддерживается.
- Надёжно можно считать только заголовок, текст, иконку приложения и адрес для тапа. Свои картинки, аватары партнёра, кнопки действий и группировку по теме на системном уведомлении не обещаем.
- С iOS 18.4 есть Declarative Web Push: уведомление можно отдать JSON-ом без сервис-воркера, но поля те же.
- Доставка на iOS бывает неполной (в обзорах называют 70–85%), поэтому «Что нового» внутри приложения источник правды, а пуш лишь повод открыть его.


## Оптимизация: как сохранять
Список уведомлений: content-visibility:auto и contain-intrinsic-size у строк, когда очередь длинная. Анимации только transform/opacity.
