Активный график на весь экран.

Шапка: закрыть, заголовок «Оценка», переключатель Нед / Мес / Год. Крупное значение выбранной недели, график гибрид: светящиеся линии «я» и партнёра с заливкой под линией, пунктирная сетка, столбики выпитого внизу, выбранная неделя подсвечена. Под графиком постоянная панель: неделя, оценка партнёра и разница, выпито, потрачено, лучшая банка со стикером. Без подсказок и без поворота телефона.
