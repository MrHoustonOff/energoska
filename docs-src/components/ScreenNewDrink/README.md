Новая банка, шаги 1–2.

Индикатор шагов и «1 из 3». Шаг 1: название, бренд (шторка выбора), сахар / без сахара. Шаг 2: теги прямо в поле и КБЖУ на 100 мл четырьмя числами. Кнопки внизу: белая «Дальше», «Назад» — вторичная.


## Энергетик
На первом шаге галочка «Энергетик», по умолчанию включена. Выключили — это не энергетик (вода, чай, кола): напиток попадает в каталог с отметкой, но не считается в статистике, рейтингах и на главной кнопке. Шаг 1 для не энергетика называется «Новый напиток».

## Добавление тега (4-й экран)
Шаг «Теги»: поле, где выбранные теги стоят чипами, а дальше печатаешь. Под полем подсказки из существующих тегов (с числом банок) и строка «Создать «текст»», если такого тега нет. После «Создать» внизу выбирается цвет нового тега: рядом показано, как тег выглядит на плитках и в фильтрах, ниже палитра. Цвет потом меняется в «Ещё → Теги». Кнопка «Добавить тег».
