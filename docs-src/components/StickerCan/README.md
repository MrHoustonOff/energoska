Банка-стикер на диске цвета банки.

Подай вырезанное фото с прозрачностью, цвет банки и наклон −5…+5°. Белая обводка 2.5px (четыре drop-shadow) и жёсткая тень 4/5px; для малых размеров 1.6px и 2/3px. Диск — круг цвета банки без размытия, чуть ниже центра. Ниже в превью состояние «фото скоро»: плоская плитка бренда с названием капслоком. Не рисуй лучи, осколки, ромбы и свечение.


## Оптимизация: как сохранять
Банки в приложении отдавать WebP с размерами под диск; не анимировать drop-shadow стикера (стопка теней дорогая). Анимируем обёртку transform.
