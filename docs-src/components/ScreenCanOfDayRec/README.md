Банка дня, вкладка «Рекомендация»: одна на день и одна на двоих, у обоих одинаковая. Три примера из четырнадцати: «Твоя пятница», «Даша по пятницам», «Давно не пили». Остальные типы и формулы: RecommendationCatalog и CanOfDayLogic.

Структура экрана: дата и пометка «одна на день», карточка с уникальным оформлением типа, название банки, плашка типа, «Почему сегодня» с оценками (ты и Даша), кнопки «Лучше рандом» (переключает вкладку) и «Беру».

## Оптимизация: как сохранять
Карточки статичные, без бесконечных анимаций. Если добавляется движение (пыль, бумажный лист), только transform/opacity и с паузой под шторкой.
