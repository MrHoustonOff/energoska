# Лейбл цены (универсальное меню)

Открывается нажатием на список «Где брал» на карточке банки. Это общий компонент для любых цен.

Сверху: название банки, заголовок «Цена» и переключатель валюты BYN / RUB. Ниже период Нед / Мес / Год / Свой и поле диапазона дат (свободный выбор). Затем фильтр по магазинам: «Все» или отдельные магазины (цвет магазина — цвет его линии).

График: линия на магазин. Жирная точка с обводкой ставится только в день, когда покупка точно известна. Между точками линия пунктирная — это оценка, а не факт. Водишь пальцем: появляется вертикаль с датой, на каждой линии точка (жирное кольцо — точная покупка, пустая — оценка).

Под графиком контекст выбранного дня: магазины по цене от дешёвого, у точных покупок надпись «куплено», у оценок «оценка по линии» и тильда у числа, у самой дешёвой плашка «дешевле». Над графиком крупная цена выбранного дня и мин / средняя / макс за период.

## Много магазинов (десятки)

Магазинов может быть очень много, поэтому они не лежат плашками в ряд.

- На карточке банки в списке «Где брал» показаны три главных магазина, затем строка «Ещё N магазинов» с рядом цветных точек и подсказкой о самых дешёвых. Нажатие открывает лейбл цены.
- В лейбле цены вместо ряда плашек стоит строка выбора: стопка цветных точек выбранных магазинов, их названия и счётчик «3 из 14 · на графике до 5». Под ней быстрые наборы: Все, 3 дешёвых, Чаще всего, Недавние, Свои.
- Нажатие на строку открывает экран «Магазины»: поиск «Найти среди 14», те же быстрые наборы сегментом, блок «Выбрано» наверху, ниже «Остальные» по алфавиту, справа буквенный индекс для быстрого перехода. У строки: флажок цвета магазина, название, число покупок и последняя дата, последняя цена, плашка «дешевле» у самого дешёвого. Внизу «Сбросить» и «Показать N».
- На графике рисуются линии только выбранных магазинов (максимум 5, чтобы график оставался читаемым). Все остальные магазины показаны одним серым коридором между самой низкой и самой высокой ценой — контекст без шума.


## Меньше шума
Страна и быстрые наборы магазинов (Все 14, 3 дешёвых, Чаще всего, Недавние, Свои) убраны с самого листа цены и живут в шторке выбора магазинов: сверху сегмент Все / РБ / РФ, ниже наборы. На листе остаются валюта, период и одна строка с выбранными магазинами.
