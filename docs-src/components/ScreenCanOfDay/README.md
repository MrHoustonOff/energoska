Банка дня, вкладка «Рандом». Вход с Главной: карточка «Банка дня». Сверху переключатель «Рандом | Рекомендация» (точка на второй вкладке, пока рекомендацию не открывали).

Состояния: готов (сводка параметров, барабан с банками, большая кнопка «Крутить»), крутится (барабан едет, кнопка гаснет), результат (банка на диске, оценки, магазин и цена, галочки «почему подошло», кубик с числом оставшихся подходящих и кнопка «Беру»), пустой результат (воронка: сколько банок осталось после каждого фильтра, убийца подсвечен, три подсказки «что ослабить»), шторка «Параметры» (две прокрутки).

Параметры: пресеты («Мой обычный», «Дёшево», «Новое», «Без сахара», свои), магазины, бюджет (диапазон) и «только свежие цены», сахар, объём, новизна, давно не пили (7/30/90), оценки (ты, Даша, «зашло обоим»), вкус (тап: хочу, ещё тап: не хочу), ядрёность, исключения (вчерашняя, ниже 5, без фото). Кнопка внизу показывает число подходящих банок вживую.

Логика и запросы: компонент CanOfDayLogic.

## Оптимизация: как сохранять
Барабан едет только transform (@keyframes reel), без blur и теней; затухание краёв статичным градиентом. Во время «Крутим» ставить только на экране крутки, на паузу уходит вместе с шторкой. Список параметров в шторке не анимируем. Проверка: lint-anim.py и perf-audit.js (Performance).

## Лимит 2 банки в день
Над списком параметров полоска «сегодня N из 2» с двумя кружками. При 1 банке кнопка результата называется «Беру · последняя на сегодня». При 2 банках экран заблокирован (ScreenCanOfDayLimit). Барабан использует картинки размера S (192) и подменяет победителя на L (384) в момент остановки; подробности в компоненте ImageLoading.
