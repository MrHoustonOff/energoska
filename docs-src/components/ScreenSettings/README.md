Настройки: карточка профиля и группы списками.

Профиль: большой квадратный аватар в цвете игрока, имя, ник и статус. Группы: партнёр (цвет и имя), тема / цвет / колонок в списке (2 | 3), справочники (бренды, магазины, теги со счётчиками), уведомления. Группа — карточка, строки 56px.


## Норма воды
Строка «Норма воды» (капля, значение в мл) открывает шторку: одно поле для ввода числа (проще тысячами: 2250), подпись «2 л 250 мл», быстрые значения 1500 / 2000 / 2250 / 2500 / 3000, «Сохранить». От нормы считаются футер, кнопка «Водичка» и сводка в «Цифрах».
