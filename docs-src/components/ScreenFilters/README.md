# Фильтры без шума

Принцип: на экране не больше одной строки управления. Главный переключатель (игрок или период) остаётся на виду, всё остальное спрятано за одной кнопкой «Фильтры» (иконка-ползунки).

- Кнопка есть на экранах «Цифры», «Банки», «Бренд», на странице магазина. Если включён хотя бы один фильтр, на кнопке цифра-бейдж (число включённых).
- Включённые фильтры показываются чипами с крестиком под главным переключателем и ссылкой «Сбросить». Когда всё стоит по умолчанию («Все»), под переключателем ничего нет.
- Шторка «Фильтры» одна на всё приложение: тип напитка (Все / Энергетики / Не энергетики) и страна (Все / Беларусь / Россия). Крупные сегменты, пояснение под каждым, «Сбросить» и «Показать N» (N — сколько записей останется).
- Фильтры общие и сохраняются между экранами: включил «Энергетики» в «Цифрах» — график, магазины и бренды показывают то же. Активный график и график цен их наследуют и своих кнопок не имеют.
- Выбор магазинов для графика цен — отдельное действие со своей шторкой (список из десятков магазинов): сверху там сегмент Все / РБ / РФ и быстрые наборы (3 дешёвых, чаще всего, недавние, свои). На самом графике остаётся одна строка с выбранными магазинами.
- Периоды (Нед / Мес / Год / Свой) — главный переключатель на графиках, остаются на виду.
