Загрузка и картинки. Банка-вырезка в памяти браузера занимает около 355 КБ (178×512×4), 300 банок дали бы около 104 МБ. Решение: четыре размера (XS 96, S 192, M 256, L 384, замеры внутри), каждый экран берёт минимально нужный; барабан держит 12 банок размера S; список «Банки» ограничен окном из 4 страниц; победитель рандома выбирается на сервере и докачивается в L, пока крутится барабан; кеш: immutable URL с версией и Service Worker (cache-first, около 300 записей).

Скрипт нарезки: assets/make-can-sizes.py.txt (сохранить как make-can-sizes.py; нужен Pillow). Он же считает цвет диска для скелетона.

## Как сохранять
Пороги веса файлов в CI (S ≤ 6 КБ, M ≤ 9 КБ, L ≤ 14 КБ). Тест на 300 плитках: не больше 110 img в DOM, CLS = 0. Память проверять в Safari Web Inspector на устройстве: числа в карточке рассчитаны по размерам файлов.
