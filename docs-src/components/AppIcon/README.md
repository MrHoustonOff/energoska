# AppIcon — знак «Энергоська»

Кольцо с молнией (из стартового экрана) и розовый круг, заходящий за него: вторая половина пары. Синий фон как у банки Gorilla. Без текста и градиентов.

- Основной файл 1024×1024 без скруглений (скругляет iOS), apple-touch-icon 180×180.
- Android maskable: знак внутри безопасной зоны 80%.
- Значок уведомления: одноцветный белый на прозрачном (кольцо и молния вырезом). На iOS в системном пуше всегда показывается обычная иконка приложения.
- favicon: без молнии, только кольцо и круг.
- Счётчик на иконке: Badge API, значение равно числу непрочитанных в «Что нового».


## Оптимизация: как сохранять
Иконка статична: SVG один раз, PNG-размеры генерировать скриптом, не загружать лишних.
