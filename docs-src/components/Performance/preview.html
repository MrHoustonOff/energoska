В iOS нет API режима энергосбережения, поэтому уровень выбирает измеритель кадров (код ниже). Внешний вид «Полного» уровня тот самый, что в макетах.

Контроллер (JS, положить в app.js)

const h=document.documentElement;
document.addEventListener('visibilitychange',()=>
  h.dataset.anim=document.hidden?'paused':'');
matchMedia('(prefers-reduced-motion:reduce)')
  .matches&&(h.dataset.perf='min');
// измеритель кадров: 2 с подряд ниже порога
let last=performance.now(),slow=0,n=0;
(function f(t){const d=t-last;last=t;
  slow=d>22?slow+d:Math.max(0,slow-d);
  if(++n>60&&slow>2000&&h.dataset.perf!=='min')
    h.dataset.perf=h.dataset.perf==='low'?'min':'low',slow=0;
  requestAnimationFrame(f)})(last);
// анимированные блоки вне экрана
new IntersectionObserver(es=>es.forEach(e=>
  e.target.style.animationPlayState=
  e.isIntersecting?'running':'paused'))
 .observe(document.querySelector('.mono'));

Правила для новых компонентов

  • Анимируем только transform и opacity.
  • Одна главная анимация на экран; остальные — тихие.
  • will-change только на бесконечных слоях, и не на десятках элементов.
  • Никаких blur, backdrop-filter, mix-blend-mode над движущимся слоем.
  • stroke-dashoffset только во время удержания кнопки.
  • Длинные списки: content-visibility:auto и contain-intrinsic-size у строк, не глобально.
  • Банки — WebP, одна кешируемая плитка зерна, шрифты с подмножеством, preload, font-display:swap.
  • Корни экранов: contain (уже в базе).

Что проверить на телефоне

  • Главная 60 секунд в простое: нагрев и расход батареи.
  • Открытие шторки и клавиатуры: пауза фона срабатывает.
  • Прокрутка каталога на 200+ строк.
  • Реальные шрифты и WebP-банки (в макетах заглушки).
  • Самый старый целевой iPhone: должен остаться на «Полном» или «Лёгком».
