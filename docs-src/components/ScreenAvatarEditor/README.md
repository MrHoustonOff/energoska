# ScreenAvatarEditor — фото профиля

Фото профиля — **всегда круг**. Пользователь выбирает снимок, а обрезка под круг делается прямо в приложении.

1. Нажатие на аватар или значок камеры в профиле открывает нижний лист: «Сделать фото», «Выбрать из галереи», «Удалить фото» (красным) и «Отмена».
2. Редактор показывает фото в квадратной сцене. Круглая рамка 280 px с белой линией 2 px и сеткой третей остаётся на месте. Двигаются и масштабируются жестами или ползунком под сценой.
3. Ниже показан предпросмотр в трёх размерах (64, 40, 28 px): так фото увидит партнёр.
4. «Готово» сохраняет, «Сбросить» возвращает исходное положение.

Правила отображения: аватар с фото — круг с кольцом цвета игрока (2 px, зазор 2 px от фона). Аватар без фото остаётся плиткой с буквой на цвете игрока. В круглых экранах партнёрства фото лежат внутри цветных кругов.
