Двадцать четыре типа рекомендаций «Банки дня». У каждого своя карточка (цвет, композиция, цифра), текст «почему» и формула расчёта на бэке с минимумом данных и весом. Типы: твоя пятница, Даша по пятницам, в это время, давно не пили, зашло обоим, спорная, выгодно сейчас, за копейки, праздник живота, по дороге, не пробовали, новый вкус любимого, в этот день, сезонная, похоже на любимое, добить коллекцию, второй шанс, выбор Даши, растёт, редкая находка, юбилей, дуэль, вторая и последняя, передышка. Колонка «При 1 банке сегодня» показывает, какие типы допустимы после первой банки; при 2 из 2 все заблокированы.

Как добавить новый тип: функция-герой h_xxx в t16a.py (сетка карточки 358×300: подпись y14, текст x18–190, арт x196–346, лента y240–288; после правки прогнать chk_ov.py), запись в RECS и INFO (причина, формула, минимум данных, вес), кандидат-запрос в daily_pick. Цвета брать из токенов (me, partner, can-*), не вводить новые бесконечные анимации.

## Оптимизация: как сохранять
Все карточки статичны. Тяжёлые фильтры (filter: saturate у «Давно не пили») допустимы только на неподвижных элементах. Новые типы проходят lint-anim.py.
