# WaterButton — кнопка воды

Лежит на главной ПОД «Энергоснулся», вдвое ниже (98 px против 196). Собрана тем же монолитом: два размытых пятна, зерно, крупное слово «Водичка» снизу, строка-подсказка сверху, справа выпито за день («1,2 из 2 л»). Слабо анимирована: дрейф пятен и две полупрозрачные волны у нижнего края; на ночь добавлены искры.

## Цвет по времени суток
Раннее утро (4–7), Утро (7–11), Ранний обед (11–12), Обед (12–14), После обеда (14–17), Вечер (17–21), Поздний вечер (21–23), Ночь (23–4). Каждому своя палитра, своя строка и свой цвет шрифта (на светлых палитрах текст тёмный).

Отдельные состояния: «Ещё не пил» (0 л) и «Цель выполнена» (слово «Норма!»).

Строки сверху — заготовки; позже их можно отдать ИИ, как у энергетика. Слово «Водичка» не меняется. Тап открывает ScreenWater. Состояния по количеству энергетиков (угасание, отталкивание) к ней не относятся.


## Оптимизация: как сохранять
Пузыри и волны только transform/opacity; на low скрываются. Новый вариант времени суток проверять perf-audit.js (45 анимаций в превью, в приложении одна кнопка).
