Кнопки, сегменты, чипы, поля и аватары.

Главная кнопка «Энергоснулся» — монолит (ActionButton): живая, затухающая, отталкивающая, замёрзшая; на карточке банки — компактная версия цвета банки (высота 96px). Остальные кнопки: белая «Дальше» (по умолчанию), серая «Назад», красная «В архив». Высота обычных кнопок 52–56px, радиус 12px. Сегмент — `surface-200` с белой активной вкладкой. Чип — радиус 6px, точка цвета записи. Поле — 52px, текст 16px. Аватары — круги в цвете игрока.

Фильтры: кнопка с иконкой-ползунками и бейджем-числом, чипы включённых фильтров с крестиком, крупные сегменты в шторке (см. ScreenFilters).


## Оптимизация: как сохранять
Бесконечные эффекты только transform/opacity; не добавлять blur/backdrop-filter на движущееся. Проверка: lint-anim.py.
