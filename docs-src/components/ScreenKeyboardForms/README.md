# Клавиатура: добавление банки

Состояния экранов, когда открыта клавиатура: название (с подсказкой «уже есть в базе»), цена (десятичная клавиатура), комментарий (многострочное поле), новый тег (шторка).

## Общие правила
- Клавиатуру не рисуем: на макете это серый блок «Системная клавиатура» с атрибутами поля. Высота: текстовая около 300 px, цифровая около 270 px (вместе с зоной «домашней полоски»).
- Главная кнопка экрана всегда над клавиатурой (стоит внизу области контента), а не прячется под ней. Шторки поднимаются и садятся прямо на клавиатуру.
- Safari не уменьшает окно при появлении клавиатуры, поэтому подъём шторок и кнопок делает приложение через `visualViewport`.
- Шрифт в полях не меньше 16 px, иначе Safari сам приближает страницу при фокусе.
- Поле в фокусе: белая рамка 1,5 px и каретка цвета игрока (в светлой теме тёмно-зелёная).
- Тап вне поля или прокрутка вниз прячут клавиатуру. У цифровой клавиатуры iOS нет клавиши «ввод», сохраняем кнопкой экрана.

## Все места, где что-то вводят
| Экран | Поле | Клавиатура и атрибуты | Где состояние |
|---|---|---|---|
| Вход | логин | текст, `autocomplete="username"`, без заглавных | ScreenLogin |
| Вход | пароль | `type="password"`, `current-password` | ScreenLogin |
| Регистрация | логин, пароль, повтор | `new-password` (iOS предлагает надёжный пароль) | ScreenRegister |
| Новый напиток | название | текст, `autocapitalize="words"` | эта карточка |
| Новый напиток | цена | `inputmode="decimal"`, принимаем «,» и «.» | эта карточка |
| Новый напиток | комментарий | многострочный, заглавная в начале предложения | эта карточка |
| Новый напиток | новый тег | текст, шторка над клавиатурой | эта карточка |
| Новый напиток | поиск бренда и магазина | `type="search"` | ScreenKeyboardSearch |
| Банки | поиск по каталогу | `type="search"`, `enterkeyhint="search"` | ScreenKeyboardSearch |
| Цена (график) | поиск среди магазинов | `type="search"` | ScreenKeyboardSearch |
| Партнёр | код приглашения | `autocapitalize="characters"`, `one-time-code` | ScreenKeyboardSearch |
| Чат банки | сообщение | `enterkeyhint="send"` | ScreenKeyboardMore |
| Магазин | название | `autocapitalize="words"`, `maxlength=24` | ScreenKeyboardMore |
| Настройки | имя | `autocomplete="nickname"` | ScreenKeyboardMore |
| Настройки | норма воды | `inputmode="numeric"` | ScreenSettings |
| Вода | число мл, объём своего стакана | `inputmode="numeric"` | ScreenWater |

Не печатаем, но вызываем системное окно: период «Свой» на графике цены (системный выбор дат), выбор фото профиля (системный выбор источника).

## Ещё не нарисовано (будет работать по тем же правилам)
Переименование бренда, магазина и тега из списков в «Настройках», изменение пароля, правка названия и комментария у уже записанной банки в «Записях». Если нужны, нарисую отдельными состояниями.
