# 05. Производительность и загрузка

Подробно: `components/Performance/`, `components/ImageLoading/`, `components/ScreenCatalogLoading/`. Инструменты: `tools/`.

## Анимации
- Только `transform` и `opacity`. Исключение: `stroke-dashoffset` кольца удержания, пока палец на кнопке.
- Пятна фона: радиальные градиенты со ступенями Гаусса, двигаются `transform` (не `filter: blur`). Переливание FAB: сдвиг слоя `::before`. Пульс кнопки: `scale + opacity` псевдоэлемента (не `box-shadow`). Скрытые контексты (`cold`, `ice`) не анимируются.
- Уровни: `html[data-perf=low]` (искры, капли, пузыри, переливание FAB, волны выключены), `data-perf=min` (всё выключено), `html[data-anim=paused]` (вкладка скрыта; также автопауза под шторкой и клавиатурой). `prefers-reduced-motion` включает `min`. Переключает измеритель кадров (iOS не даёт API режима энергосбережения).
- Результат замеров (Chromium без экрана, сравнение до/после): Главная Paint 484 → 0, Raster 250 → 5; кнопки Paint 2169 → 567, Raster 964 → 0. На iPhone не проверено.

## Картинки
Один файл банки 178×512 в памяти около 355 КБ. 300 банок = ~104 МБ. Решение: размеры XS 96 (1,6 КБ), S 192 (4,3), M 256 (6,3), L 384 (10,4); плитка M, карусель S (12 штук), результат и карточка L; окно списка 4 страницы по 24; победитель рандома выбирается сервером до анимации и докачивается в L параллельно. Кеш: immutable URL + Service Worker (cache-first, ~300 записей), JSON stale-while-revalidate, первая страница в IndexedDB. Скрипт нарезки: `tools/make-can-sizes.py`.

## Список «Банки»
Курсорная пагинация, `IntersectionObserver` с `rootMargin: 800px`, скелетон тех же размеров (CLS = 0), поиск на сервере с дебаунсом 200 мс и `AbortController`, старый список приглушён до ответа, позиция прокрутки в `history.state`, при ошибке картинки плитка с повтором, при отсутствии сети сохранённая страница и жёлтая плашка.

## Проверки
`python3 tools/lint-anim.py components` (keyframes только transform/opacity), `tools/perf-audit.js` (выполнить на странице: запущенные анимации и не-композиторные свойства), `tools/perf.py` (трассировка Playwright), `tools/chk_ov.py` (наложения текста). Пороги веса: S ≤ 6 КБ, M ≤ 9 КБ, L ≤ 14 КБ. Память смотреть в Safari Web Inspector на устройстве.
