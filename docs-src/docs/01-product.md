# 01. Продукт

## Что это
Энергоська: мобильное PWA (iOS Safari, «Добавить на экран Домой») для двоих. Пара собирает энергетики, ставит оценки, сравнивает цены в магазинах Беларуси и России, ведёт статистику и воду. Тон: быстро, цифрами, чуть дерзко, но без поощрения перебора: **максимум 2 банки в день**.

## Пользователи
Двое (в макетах «Я» и «Даша»): у каждого свой цвет (по умолчанию лайм и розовый), аватар, список оценок. Все данные общие внутри пары: банки, магазины, бренды, теги, цены. Оценки у каждого свои, видны обоим.

## Карта переходов
Главная → «Энергоснулся» (запись банки → оценка) · «Водичка» (ScreenWater) · «Банка дня» (рандом | рекомендация) · колокольчик (ScreenNotifications) · аватары (профиль).
Нижняя панель: Главная, Банки, центральная молния (быстрая запись), Цифры, Ещё. «Ещё» ведёт в справочники (бренды, магазины, теги), партнёрство, настройки, уведомления.
Банки → карточка «Витрина» → оценка / чат / цены; плитка «фото скоро» ведёт в ту же карточку с состоянием ожидания.
Цифры → активный график (на весь экран), лейбл цены (шторка), водяная сводка (свёрнутая/развёрнутая).

## Жёсткие правила продукта
1. Максимум 2 энергетика в день. Лесенка кнопки: 0 живая, 1 затухает, 2 лимит (замёрзла). Сверх лимита только удержанием 3 секунды, пометка «сверх лимита», красный день, сброс серии «дней в лимите». Никаких отдельных состояний для 3, 4 и больше.
2. Энергетик определяется одной галочкой при добавлении (по умолчанию включена). Не энергетики не влияют на счёт, рейтинг и кнопку.
3. Оценка = 4 параметра, шаг 0.1, итог средний; показываем «было X.X» и оценку партнёра, если они есть.
4. Страна у банки и магазина обязательна. Цены разных стран не сравниваются.
5. Вода: норма в настройках (по умолчанию 2250 мл), уровень футера = выпито / цель; сводка воды закреплена сверху «Цифр».
6. «Банка дня»: либо рандом по параметрам, либо одна общая рекомендация на день (детерминированная по паре и дате). Выбранная «Беру» фиксируется и видна партнёру.
7. Уведомления четырёх типов: партнёр выпил энергетик или воду; партнёр закрыл норму воды; партнёр добавил банку, магазин или бренд; фото обработано. Внутри приложения красивые тосты, вне приложения системный push (ограничения в `05-performance.md` и README ScreenNotificationSetup).
