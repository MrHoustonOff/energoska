# 06. Решения: замороженные, отклонённые, открытые

## Заморожено (менять только по прямой просьбе владельца)
- Стиль: Unbounded для текста, Oswald для чисел; вырезанные банки-стикеры на дисках цвета банки; цвета игроков (я — лайм, партнёр — розовый по умолчанию); фон «Глубина» + слабый PNG-шум; чат в стиле iMessage.
- Дизайн шторки «Лейбл цены» (ScreenPriceSheet) и выбор магазина.
- Бутылка «Водичка»: простая, без бликов, без крышки, закруглённая открытая сверху полость, подпись «Водичка» без смайлика, заполняется.
- Слово «Энергоснулся» на главной кнопке.
- Лимит 2 банки в день и его лесенка.
- Футер с водой и кнопка воды под монолитом.
- Правило «фон меняет только фон».

## Технические решения, ЗАМОРОЖЕНЫ (проверено на реальном iPhone 02.10.2026; детали — `07-app-shell.md`, `08-push.md`)
- **Каркас:** `html`/`body` `height:100%` (без `position:fixed`/`overflow:hidden`), корень `#app` в пикселях из JS: `visualViewport.height + offsetTop + gap`, `gap = screen − innerHeight` (вычисляется, не зашит). Заменил ранний рецепт «`position:fixed; inset:0`» и «flex на `100dvh`» из первых версий документов.
- **Статус-бар:** `black-translucent` (полноэкранный вид); `black` отклонён (сплошной чёрный статус-бар).
- **Meta viewport:** `width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover`, **без** `interactive-widget`.
- **Клавиатура:** «родной» режим: окно не сжимаем, страницу прокручивает iOS; запас под клавиатуру (2× высоты) с равным ростом нижнего отступа списка; запрет прокрутки страницы пальцем при вводе; докрутка низкого поля через 0.26 и 0.7 с; плавный возврат наверх сразу на `focusout`. Режимы «фикс» и «текущий» отклонены.
- **Нижняя панель вкладок:** поверх списка (`position:absolute`), а не в потоке (ранее документы требовали «в потоке»); при вводе уезжает вниз (`transform`, **без** прозрачности), появляется с задержкой 0.22 с; приклеена к низу экрана, пока приложение удлинено.
- **Поля без клавиатуры** (`date`, `time`, `select`, флажки и т.п.) клавиатурную логику не запускают.
- **Push-уведомления:** service worker только для push (без `fetch` и кэша); отправка в тесте — dev-заглушка на компьютере, HTTPS через туннель `cloudflared`; ключи VAPID один раз, не менять.
- **Отладка:** Лаборатория (`Ещё → Лаборатория`), лог с копированием в буфер, красный фон страницы — остаются как служебные инструменты до выхода в продукт.

## Принято
Тёмная тема основная; одна строка управления; общие фильтры; страны РБ/РФ; оценка 4 параметра шаг 0.1; «фото скоро» как состояние; клавиатурные состояния для всех полей; 24 типа рекомендаций; четыре размера картинок; окно списка из 4 страниц; уровни `data-perf`.

## Отклонено
Бренд-акцент (оранжевый и т.п.); лучи, осколки, ромбы, мягкое свечение; размытые тени; капсулы вместо радиуса 12; блики и крышка бутылки; нативный `range` для оценки; шторка для оценки; ступени «3 банки и больше»; экранный цифровой блок поверх системной клавиатуры; логотип с буквами.

## Открыто (спрашивать у владельца)
1. Норма воды по умолчанию (2250 мл в настройках) и как показывать «2,25 л».
2. Граница суток для счётчиков (полночь или 04:00) и часовой пояс пары.
3. Пороги данных для рекомендаций (8 записей по дню недели у тебя, 6 у партнёра) и веса типов.
4. Время уведомления «Банка дня готова» по умолчанию (сейчас 11:00).
5. Восстановление пароля, лимит попыток входа и срок блокировки.
6. День получки (дни 1–3 и 15–17 или своя настройка).
7. Реальные фото банок: вес выше вырезок, нужны пороги CI.
8. Реальная проверка скорости на iPhone (нагрев, батарея, прокрутка 200+ банок).
9. Показывать ли партнёру «Беру» как событие в ленте или только как уведомление.
10. Минуты порога для сводки «за короткое время» в push.
