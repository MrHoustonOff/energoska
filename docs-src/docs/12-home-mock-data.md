# 12. Главная: что берётся из данных, а что мокается «в лоб»

Кнопка «Энергоснулся» (`src/home/energyLooks.ts`, правила выбора — `src/domain/energyContext.ts`, таблица сценариев в `scenarios.ts`) реализует ВСЕ формы из `ActionButton/preview.html`: 13 контекстов × ступени 0/1/2 банки, ночной вид, «не энергетик записан», удержание 3 с. Увидеть любую форму без смены времени: **Ещё → Лаборатория → «Кнопка «Энергоснулся»: формы»**, затем открыть «Главную».

| Что нужно кнопке | Откуда сейчас | Что будет на бэкенде |
|---|---|---|
| Мои банки за день, банки партнёра за день | `GET /intakes/day-summary` (`energy_count`, `partner_energy_count`): настоящие данные мока | то же |
| Последний напиток без галочки «Энергетик» | `last_soft_drink`: считается моком по записям | то же |
| Счёт «кто больше пил за всё время» (контекст «ты впереди», `3:1`) | `duel`: мок всегда отдаёт `{me:0, partner:0}` (контекст не включается) | считает бэкенд (блок «Цифры») |
| Серия дней в лимите (контекст «серия») | `streak_days`: мок отдаёт 0 | считает бэкенд (блок «Цифры») |
| Юбилей, следующая банка 100-я | `jubilee_next`: мок отдаёт `false` | считает бэкенд |
| Фразы «ИИ» | всегда заготовки из макета | генерация фраз — отдельная работа бэкенда |
| Банка дня на главной | `GET /day-pick`: только из демо-данных (`MOCK-DEMO`) | подбор — блок «Банка дня» |

Время (утро, обед, вечер, ночь) и день недели берутся из часов телефона по поясу пары; границы часов — в `energyContext.ts`.
