# Энергоська (PWA-прототип, только фронтенд)

Документация и эталонная вёрстка лежат в `docs-src/` (начни с `docs-src/AGENTS.md`).

## Запуск на телефоне
```bash
git clone https://github.com/MrHoustonOff/energoska && cd energoska
npm i
npm run dev          # в консоли появится Network: http://192.168.x.x:5173
```
1. Телефон и компьютер в одной Wi-Fi сети. Открой адрес из `Network:` в Safari.
2. Поделиться → «На экран Домой». Запускай с иконки (это режим standalone, во вкладке Safari картина другая).
3. После смены manifest, иконок или `apple-mobile-web-app-*` мета-тегов удали иконку и добавь заново (iOS читает их только при установке).

## Dry start: чек-лист на телефоне
Четыре вкладки: **Старт**, **Ввод**, **Скролл**, **Итог**. На каждой один вопрос и кнопки «Да / Нет». На вкладке «Итог» сводка и блок для скриншота.

1. **Старт.** Закрой приложение полностью, открой с иконки: нет чёрных полос сверху и снизу? Нажми +1, закрой и открой: число на месте?
2. **Ввод.** Тапни нижнее поле: шапка на месте, поле над клавиатурой, панели внизу нет? Закрой клавиатуру: всё вернулось, чёрной линии нет?
3. **Скролл.** Двигается только список, шапка и панель стоят?

Рецепт каркаса и клавиатуры описан в `docs-src/SAFARI_PWA_BIBLE.md` §4.2 (отметка «ПРОВЕРЕНО НА УСТРОЙСТВЕ»), код в `src/viewport.js` и `src/styles.css`.
