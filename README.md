# Энергоська (PWA-прототип, только фронтенд)

Документация и эталонная вёрстка лежат в `docs-src/` (начни с `docs-src/AGENTS.md`).

## Запуск на телефоне
```bash
git clone https://github.com/MrHoustonOff/energoska && cd energoska
npm i
npm run dev          # в консоли появится Network: http://192.168.x.x:5173
```
1. Телефон и компьютер в одной Wi-Fi сети. Открой адрес из `Network:` в Safari.
2. Поделиться → «На экран Домой». Запускай с иконки (это режим standalone, во вкладке Safari картина другая).
3. После смены manifest или иконок удали иконку и добавь заново.

## Dry start: что проверяем (экран «Главная» → «Диагностика»)
1. Запуск без чёрной полосы сверху и снизу, без «потяни вниз, чтобы починилось».
2. Клавиатура не ломает вёрстку (экран «Ввод»): шапка на месте, нижняя панель уезжает, поле не прячется, после закрытия нет полосы.
3. Скролл (экран «Скролл»): листается только список, страница и каркас не двигаются.

Переключатели «Каркас» (`fixed inset 0` / `100dvh`) и «Клавиатура» (`pan` / `resize`) нужны, чтобы на телефоне сравнить подходы. Выбор сохраняется.
