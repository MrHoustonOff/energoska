# Энергоська (PWA-прототип, только фронтенд)

Документация и эталонная вёрстка лежат в `docs-src/` (начни с `docs-src/AGENTS.md`).

## Запуск на телефоне
```bash
git clone https://github.com/MrHoustonOff/energoska && cd energoska
npm i
npm run dev          # в консоли появится Network: http://192.168.x.x:5173
```
1. Телефон и компьютер в одной Wi-Fi сети. Открой адрес из `Network:` в Safari.
2. Поделиться → «На экран Домой». Запускай с иконки (это режим standalone, во вкладке Safari картина другая).
3. После смены manifest, иконок или `apple-mobile-web-app-*` мета-тегов удали иконку и добавь заново (iOS читает их только при установке).

## Что сейчас в приложении
Одна страница **«Поля»**: все виды полей ввода (текст, поиск, email, телефон, ссылка, цифры, цена, пароль, дата, время, список,
многострочное, редактируемый блок) и панель вкладок. На ней отрабатываются два аспекта:

1. **Запуск** с домашнего экрана без чёрных полос сверху и снизу.
2. **Клавиатура**: открывается и закрывается плавно, поле видно над ней, под ней нет «края приложения», панель вкладок уезжает и
   возвращается без наложения на уход плавающей панели клавиатуры.

Остальные вкладки панели пока заглушки.

## Отладка на телефоне
Внизу страницы блок **«Отладка»**:
- **Красный фон**: подсвечивает фон страницы за приложением (в боевых цветах он равен фону приложения);
- **Копировать лог**: копирует в буфер отчёт (метрики, две записи про клавиатуру, лог тапов и фокуса) для отправки разработчику;
- **Обновить / Очистить лог**: показать отчёт в блоке ниже / стереть лог.

## Где что лежит
- `src/viewport.js`: высота окна и клавиатура (в начале файла подробно описано, как устроено и почему).
- `src/styles.css`: стили, каркас, панель вкладок, поля.
- `src/main.js`: разметка страницы, отладочный блок.
- `src/store.js`: Mock-Store (localStorage). `src/eventlog.js`: лог для отладки.
- `docs-src/SAFARI_PWA_BIBLE.md` §4.2 и §5.6: проверенные на устройстве рецепты запуска и клавиатуры.

## Контрольная точка
Ветка `checkpoint/kb-best-1`: состояние клавиатуры до полной переписи кода (с режимами и переключателями).
