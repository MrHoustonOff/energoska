# ScreenWaterStats — водяная сводка на «Цифрах»

Сверху экрана «Цифры» под переключателем Я / Даша / Оба всегда закреплена карточка воды, остальная статистика прокручивается под ней.

- **Свёрнутая** (по умолчанию, 70 px): кольцо прогресса, выпито сегодня, «из 2,25 л · серия N дн», мини-гистограмма недели, стрелка вниз.
- **Развёрнутая** (по тапу, в том же месте): переключатель Нед / Мес / Год, среднее за день с дельтой к прошлому периоду, гистограмма с пунктирной линией нормы, тепловая карта, три плитки и строка-инсайт. Стрелка вверх сворачивает.
- Неделя: гистограмма по дням, тепловая «когда пьёшь» по шести слотам дня. Месяц: гистограмма по неделям, тепловая календарём. Год: гистограмма по месяцам, тепловая на весь год (52 недели × 7 дней).
- Столбцы за норму яркие, ниже нормы приглушены. Сегодняшний подписан жирным.
- **Синхронизация с партнёром:** выбор Я / Даша / Оба общий для всей страницы «Цифры», карточка воды ему подчиняется. «Оба»: парные столбцы цветами игроков, два числа, плитки «вместе в норме», «серия обоих», «разница»; на тепловой карте светится день, когда в норме оба.
- Дополнительная статистика: серия дней в норме и рекорд, дней в норме, лучший день, воды на один энергетик, пик питья, разница между партнёрами.

Фильтры «Энергетики / Не энергетики» вода не затрагивает. Данные в макете демонстрационные.
