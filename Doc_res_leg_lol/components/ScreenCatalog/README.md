Список банок в две колонки.

Заголовок и кнопка поиска, ряд чипов-фильтров (Все, Любимые, С сахаром, Не пробовал). Плитка: диск цвета банки со стикером, название до двух строк, оценка `score` цветом «я» и оценка партнёра. Без фото — плоская плитка цвета бренда с названием капслоком, меткой «Фото скоро» и названием банки; пропорции те же, что у фото-плитки. В настройках колонок 2 или 3.


## Не энергетики
В фильтрах чип «Не энергетики»: по умолчанию каталог показывает энергетики, не энергетики видны только по этому чипу.


## Оптимизация: как сохранять
Длинный список: content-visibility:auto и contain-intrinsic-size у строки (не глобально), миниатюры WebP с lazy-loading. Анимации строк только transform/opacity. Проверка: lint-anim.py, perf-audit.js.
