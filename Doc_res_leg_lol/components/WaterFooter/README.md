# WaterFooter — футер, наполняемый водой

Таб-бар получает слой воды (`.wtr`) под иконками. Уровень: `--lv` от 0 до 1, это выпитое за день, делённое на цель дня. `tabbar(active, water=lv)` в генераторе; при 100% футер залит полностью.

## Как устроено (быстро на iOS)
- Слой воды один: контейнер 100 px с `overflow:hidden`, внутри блок `.lv`, который сдвигается через `transform: translateY` (смена уровня анимируется плавной транзицией по `transform`, не по высоте).
- Две волны — SVG шириной 200%, анимируются только `translateX` (разные скорости, направления и длина волны, слои разнесены по высоте на ~11 px, поэтому вода «волнистая»). Пузырьки: `transform` + `opacity`.
- Нет анимированных `blur`, `backdrop-filter`, `mix-blend-mode` и `filter` поверх движущегося слоя; зерно статично и лежит под водой, поверх воды зерна нет (старое наложение `overlay` с таб-бара снято).
- Фон таб-бара прозрачный, подписи иконок читаются через `text-shadow` и более плотный цвет неактивных пунктов.
- Нужно проверить на реальном iPhone: плавность (60/120 Гц), расход батареи, поведение при сворачивании PWA (при `visibilitychange` анимацию ставить на паузу). `prefers-reduced-motion`: волны не двигаются.
- Вода обновляется только когда меняется уровень (тап по воде), в остальное время работает один композитный слой.

Тема: тёмная — вода прозрачнее, светлая — светло-голубая с тёмной подписью.


## Оптимизация: как сохранять
Волны движутся translate по слоям, без перерисовки; на уровне data-perf=low останавливаются. Уровень воды меняется через transform/clip, не через анимацию высоты. Проверка: lint-anim.py.
