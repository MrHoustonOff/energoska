Список «Банки»: четыре состояния загрузки. 1) Холодный старт без кеша: скелетон тех же размеров, что плитка (диск в цвет банки из поля dominant, блик едет через transform). 2) Догрузка при прокрутке: плитки с плавным появлением картинки (fade 250 мс), внизу индикатор «загружаем ещё». 3) Нет сети: жёлтая плашка, показаны сохранённые, одна плитка с ошибкой картинки и повтором. 4) Поиск: прошлый список приглушён и не мигает, пока идёт новый запрос.

Подробные правила выгрузки: компонент ImageLoading (страницы по 24, окно DOM из 4 страниц, IntersectionObserver с rootMargin 800 px, кеш первой страницы в IndexedDB, сохранение позиции прокрутки).

## Оптимизация: как сохранять
Скелетон и индикатор крутятся только пока видны. Плитки одинаковой фиксированной высоты, чтобы CLS был 0. Картинка M (256), не L.
