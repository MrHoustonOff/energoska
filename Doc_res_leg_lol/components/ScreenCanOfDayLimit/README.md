Банка дня при суточном лимите в 2 банки (жёсткое правило продукта).
Четыре экрана: результат рандома при 1 банке (кнопка «Беру · последняя на сегодня»), рекомендация «Вторая и последняя» (разрешены только лёгкие типы), «Дуэль» (две банки с одинаковой оценкой, выбор одной), экран при 2 из 2: замороженная банка с замком, «Лимит на сегодня», когда появится завтрашняя банка, кнопка «Водичка» и «Настроить рандом на завтра».

## Оптимизация: как сохранять
Экран при лимите статичный; новых анимаций не добавлять. Остальное по правилам компонента Performance.
