Как считается «Банка дня» на бэке: ночная задача daily_pick (взвешенный детерминированный выбор типа по seed = hash(couple_id + date)), запрос генератора рандома с параметрами, воронка пустого результата, таблицы daily_pick, pick_state, pick_presets, drink_stats, правила (не повторять банку 14 дней, тип 3 дня подряд, уведомление в 11:00).

Открытые вопросы: пороги данных (8 и 6 записей), веса типов, время уведомления по умолчанию, считаем ли «день» по часовому поясу пары.

## Как сохранять
Любое изменение логики сначала в этой карточке, затем в коде. Запрос рандома гонять с EXPLAIN на таблице 10 000 банок, цель до 50 мс.

Лимит: максимум 2 банки в день. При 1 банке допускаются только типы с пометкой «лёгкий» (last_one, rest, daypart, thrifty, shop_near, rare_gem, climb), при 2 выбор заблокирован. Типов теперь 24.
