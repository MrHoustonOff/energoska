# ScreenWater — добавить воду

Один экран, ничего лишнего. Четыре состояния: основной, зажатый свой стакан (меню), шторка «Свой стакан», ввод числа с клавиатуры.

- По центру «банка водички»: вырезанный стикер на цветном диске (как банки энергетиков), прозрачный корпус, внутри вода; название «ВОДИЧКА» вдоль банки. Под ней число. Ползунок 0–1 л, шаг 25 мл; банка наполняется вместе с ползунком. Тап по числу: поле в фокусе и поднимается системная цифровая клавиатура (своей клавиатуры не рисуем), от 25 до 2000 мл.
- Ниже сетка 3×2. Первый ряд: мини-банки по умолчанию 125, 250, 500 мл. Второй ряд: свои стаканы (до трёх), пустые места: пунктирная рамка с плюсом, затем бледная пустая.
- Зажатие своего стакана: он приподнимается, остальное затемняется, над ним меню «Изменить объём» / «Удалить» (красным). У стандартных стаканов меню нет.
- «Изменить объём» и плюс открывают одну шторку: объём, быстрые значения, «Сохранить»; у существующего ещё «Удалить» (пунктирная красная кнопка). У нового стакана кнопки «Удалить» нет.
- Белая кнопка «Добавить N мл» внизу. Тап по стандартному стакану выбирает его объём (подсветка синей рамкой), не добавляет сразу.
- Вода: `#4aa3ff` / `#2a7df0`, два слоя волны. Анимируются только `transform` (волна и пузырьки); `prefers-reduced-motion` отключает.

Открытые вопросы: суточная цель (по умолчанию 2 л) и где её менять; в какое время сбрасывается день (как у счётчика энергетиков).

Бутылка: максимально простая. Плоский тёмно-синий корпус на белом контуре стикера, сверху открыто (без крышки), внутри вода с волнистой поверхностью, надпись «ВОДИЧКА» вдоль корпуса. Без бликов, значков и пузырей.


## Оптимизация: как сохранять
Бутылка заполняется transform; капли и пузыри скрываются на low, всё замирает на min. Не добавлять блики и blur (дизайн и скорость).
