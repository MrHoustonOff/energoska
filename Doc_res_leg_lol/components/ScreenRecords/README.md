Справочники: бренды, магазины, теги.

Заголовок и «+», сетка цветных плиток в три колонки с названием капслоком и числом банок, строка «Архив». Нажатие на плитку открывает шторку правки: название, палитра, предупреждение о каскаде («Архивация бренда уберёт из списка и все его банки: 4 шт.»), кнопки «Архивировать» и «Сохранить».


## Оптимизация: как сохранять
Длинный список: content-visibility:auto и contain-intrinsic-size у строки (не глобально), миниатюры WebP с lazy-loading. Анимации строк только transform/opacity. Проверка: lint-anim.py, perf-audit.js.
