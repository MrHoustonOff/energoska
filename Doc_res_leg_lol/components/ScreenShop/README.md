# Магазин

Три экрана в одном макете: страница магазина, редактирование и рейтинг магазинов по странам.

**Страница магазина.** Круглое фото магазина с кольцом его цвета, название, страна (РБ / РФ). Карточка рейтинга магазина: индекс от 0 до 10, место внутри своей страны («№2 из 9»), насколько магазин дешевле или дороже среднего, считается по средней относительной цене на общие энергосы. Плитки «Самых дешёвых» и «Покупок». Ниже все энергосы, купленные здесь, с ценами. Если в этом магазине энергос самый дешёвый среди магазинов своей страны, у него плашка «Самый дешёвый», иначе показано, на сколько дороже минимума. Рядом с заголовком списка кнопка «Фильтры» (общие фильтры типа и страны), ниже чипы сортировки: по цене, свежие, по оценке.

**Редактирование (CRUD).** Нижний лист «Магазин»: круглое фото (сделать, выбрать, убрать), название, страна Беларусь / Россия, цвет. Удаление работает как архив: «В архив». Создание нового магазина — плюс в списке магазинов.

**Рейтинг магазинов.** Переключатель Все / РБ / РФ. При «Все» страны идут отдельными группами, у каждой свой лучший магазин с короной. Магазины РБ и РФ между собой не соревнуются.

## Магазин без фото
Если фото нет, магазин показывается круглой плашкой: первые две буквы названия (ПО, GR, АЛ) заглавными на фирменном цвете магазина, с тем же кольцом, что у фото. Цвет букв выбирается сам по контрасту (чёрный на лайме, розовом, бирюзовом, жёлтом и оранжевом, белый на синем, красном и фиолетовом). Так магазин выглядит везде, где обычно фото: страница магазина, рейтинг, список магазинов в шторке выбора, подписи на графике. Появилось фото — буквы заменяются им. Смена цвета в шторке «Магазин» сразу меняет плашку.


## Оптимизация: как сохранять
Длинный список: content-visibility:auto и contain-intrinsic-size у строки (не глобально), миниатюры WebP с lazy-loading. Анимации строк только transform/opacity. Проверка: lint-anim.py, perf-audit.js.
