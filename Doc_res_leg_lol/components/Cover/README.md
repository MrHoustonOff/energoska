# Cover
Обложка дизайн-системы и источник геометрической айдентики: слово «Энергоська» (Unbounded 800), подпись «Собираем и оцениваем энергетики вдвоём» и четыре цветных блока цветов банок (синий, лайм, розовый, красный) с кольцами и кругами. Тот же язык колец повторяется в знаке приложения и на стартовом экране входа. В самом приложении не используется. Цвета берутся только из токенов `can-*`, `me`, `partner`.
