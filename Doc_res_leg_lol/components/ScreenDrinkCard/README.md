Карточка банки «Витрина». В макете экран прокручивается колесом мыши, полоса прокрутки скрыта.

Порядок блоков сверху вниз: 1) шапка, стикер на диске, бренд и название, оценка 100px, оценка партнёра и четыре параметра с засечкой партнёра; 2) плашка КБЖУ на 100 мл: крупные ккал, полосы Б / Ж / У, строка «банка 450 мл — 18 ккал целиком», пометка «Без сахара»; 3) теги вкуса крупными цветными плашками (манго, кокос и т. п.); 4) раскрывающийся список «Где брал» с магазинами, последней ценой и мини-линией, внизу строка «Динамика цен» — по нажатию на список открывается лейбл цены (ScreenPriceSheet); 5) комментарии как чат iMessage, значок «развернуть» открывает чат на весь экран; 6) внизу кнопка «Энергоснулся» цвета банки.

Чат на весь экран: сверху лейбл энергетика, снизу поле «Написать в чат» и кнопка отправки цветом игрока. Писать можно в любой момент, отправленные сообщения нельзя править и удалять.

Без фото слева плоская плитка бренда.
