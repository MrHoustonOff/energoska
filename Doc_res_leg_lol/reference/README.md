# reference/energoska.css
Классы эталонной вёрстки. Продуктовые: `.num` `.sec` `.mut` `.card` `.grp` `.chip` `.seg` `.tag` `.fld` `.cta` `.ib` `.top` `.tab` `.ti` `.fab` `.sheet` `.hd` `.dim` `.stk` `.can` `.mono` (+`.bl`, `.pill`, `.spin2`, `.cold`, `.ice`, `.dim`) `.wtr` (футер воды) `.hold`, `.kbd`. Леса макета (не переносить): `.scr`, `.scb`, `.sb`, `.isl`, `.hi`, `.row2`, `body{padding:20px}`.
Цвета банок в превью приходят из классов `.k-<id>{background-image:url(...)}`: в приложении подставляй `assets/cans/<id>.<size>.webp`.
Оптимизационный блок («governance») в конце: contain, паузы, `data-perf`, `data-anim`. Не удалять.
